## 摘要
多模态图推荐将观测到的交互与物品图像和文本相结合，以学习用户偏好。这些输入构成了语义-行为证据（Semantic-Behavioral Evidence, SBE）。许多现有图方法融合了协同与多模态语义关系，然而其聚合与状态更新仍处于上下文分离的状态，限制了偏好证据跨层的连续组合以及多源信息的联合使用。为解决这一局限，我们提出 CC-MGRec，一种上下文耦合图学习方法，将 SBE 组织在共同的图学习上下文中，以进行跨关系建模和组合传播。其上下文耦合多模态图整合了用户-物品协同关系和物品-物品语义关系，并通过联合归一化协调它们的消息尺度。基于推荐的语义校准利用训练行为调整语义邻居权重，同时保留归一化后的协同传播系数。协同-语义组合传播逐层更新共享节点状态，以持续组合协同与多模态语义证据，隐式形成偏好证据链（Preference Evidence Chains, PECs），包括协同-语义与视觉-文本 PEC。在每一层中，对同一共享节点状态联合执行关系消息，可在保持传播输出的同时减少中间输出处理与融合开销。我们提供了所提机制的理论分析。在三个 Amazon 数据集上的实验表明，推荐质量得到提升，且图传播过程中的推理速度更快。

## Abstract
Multimodal graph recommendation integrates observed interactions with item images and text to learn user preferences. These inputs constitute Semantic-Behavioral Evidence (SBE). Many existing graph methods incorporate collaborative and multimodal semantic relations, yet their aggregation and state updates remain context-separated, limiting the continuous composition of preference evidence across layers and the joint use of multiple sources. To address this limitation, we propose CC-MGRec, a context-coupled graph learning method that organizes SBE within a common graph learning context for cross-relation modeling and compositional propagation. Its context-coupled multimodal graph integrates user-item collaborative relations and item-item semantic relations, coordinating their message scales through joint normalization. Recommendation-grounded semantic calibration uses training behavior to adjust semantic neighbor weights while preserving normalized collaborative propagation coefficients. Collaborative-semantic compositional propagation updates shared node states layer by layer to continuously compose collaborative and multimodal semantic evidence, implicitly forming Preference Evidence Chains (PECs), including collaborative-semantic and visual-textual PECs. Joint execution of relation messages on the same shared node states within each layer preserves propagation outputs while reducing intermediate output processing and fusion overhead. We provide theoretical analysis of the proposed mechanisms. Experiments on three Amazon datasets demonstrate improved recommendation quality and faster inference during graph propagation.

## 1. 核心问题与研究动机

- **背景**：多模态图推荐将用户-物品交互、物品图像与文本统一建模，这些输入被作者统称为**语义-行为证据（Semantic–Behavioral Evidence, SBE）**。现有方法（如 MMGCN、GRCN、LATTICE、FREEDOM、MIG-GT、DHMRec 等）已能引入协同关系与物品-物品语义关系，并设计了多种融合、对齐或阶段式迁移策略。
- **核心问题**：现有方法的**聚合与状态更新仍处于“上下文分离”（context-separated）状态**——协同关系与语义关系各自维护独立的状态流，二者不在每一层共同更新同一份节点状态。这导致：
  1. 偏好证据难以跨层连续组合（例如交互证据无法经语义关系继续传播）；
  2. 多源信息无法真正联合利用。
- **作者定义的“图学习上下文”**：由节点信息、加权关系邻域、归一化方式、状态更新方式共同构成的学习环境。
- **核心概念——偏好证据链（Preference Evidence Chains, PECs）**：多层图学习隐式形成的、有序加权的传播贡献。作者区分两类新增 PEC：
  - **协同–语义 PEC（C–S PEC）**：交互证据经物品语义关系继续传播，语义证据回流协同学习；
  - **视觉–文本 PEC（V–T PEC）**：某一模态聚合的证据经另一模态关系继续传播。
- **初步诊断实验**（论文动机的实证支撑）：
  - Baby 数据集上，C–S PEC 支持覆盖 10.84% 的留出正例，而匹配的未见对照仅 1.32%，差距 **8.19×**；
  - 在固定训练模型中移除 V–T PEC 贡献，高曝光组的 Hit@20 下降最大（+2.63pp），部分低曝光组变化小甚至提升。

## 2. 方法论：CC-MGRec

### 2.1 总体框架

CC-MGRec 由三个协同组件构成：
- **CC-MG**（Context-Coupled Multimodal Graph Construction）：构建上下文耦合多模态图；
- **RGSC**（Recommendation-Grounded Semantic Calibration）：推荐驱动的语义校准；
- **CSCP**（Collaborative–Semantic Compositional Propagation）：协同–语义组合传播。

最终将多模态内容、观测交互与行为共现信息组织进**同一个图学习上下文**，支持跨关系连续证据组合与高效推理。

### 2.2 关键技术细节

**(1) 语义邻域构建**
- 对模态 $m \in \{v, t\}$，用投影函数 $f^m$ 将物品特征映射到共享 $d$ 维空间，L2 归一化得到 $z_i^m$，取非负亲和度 $g_{ij}^m = [ (z_i^m)^\top z_j^m ]_+$；
- 各模态取 top-$K$ 邻居，任一端点检索到对方即保留（式 5），合并得到语义边集 $\mathcal{E}_s$。

**(2) 行为信息驱动的模态权重**
- 用共现参考 $o_{ij} = |\mathcal{U}_i \cap \mathcal{U}_j| / \sqrt{d_i d_j}$ 及其 top-$K$ 邻居 $\mathcal{C}_i$ 计算平均重叠 $a_m$；
- 经温度 $\tau_\alpha$ 的 softmax 得到全局模态权重 $\alpha_m$（式 6）；
- 原始语义边权 $w^s_{i \to j} = \beta \sum_m \alpha_m B^m_{ij} g^m_{ij}$（式 7）。

**(3) 推荐驱动的语义校准（RGSC）**
- **行为相关性**：将每个用户历史划分为 $F_u = \min(F, |\mathcal{N}_u|)$ 折，计算上下文-目标共现的对数提升 $\ell_{i \to j}$（式 1），再经双端置信度 $\chi_{ij}$ 与 tanh 变换得到 $\phi_{ij}$（式 2）；
- **预算保持重分配**：中间权重 $\tilde{w}^s_{i \to j} = w^s_{i \to j} \exp(\gamma \phi_{ij})$（式 3），再按目的地归一化恢复原始入边预算 $B^s_j$（式 4）；
- **不变性**：保持每条目的入边语义预算不变，因此联合度矩阵与归一化协同传播系数保持不变（Lemma A.7）。

**(4) 多模态节点信息**
- 物品锚点：$\tilde{s}_i = \text{norm}(\sum_m \alpha_m z_i^m)$（式 8）；
- 用户锚点：历史物品锚点加权（$\pi_{ui} \propto (d_i+1)^{-1/2}$）加组级原型 $c_u$（式 9）；
- 初始状态：$h_p^{(0)} = e^{id}_p + s_p \tilde{s}_p$，物品带可训练尺度 $\delta_i$（式 10）。

**(5) 度数与画像感知的交互权重**
- 画像一致度 $q_{ui} = [\cos(\tilde{s}_u, \tilde{s}_i)]_+$，度数门控 $\eta_i = \sigma(a_c \log(d_i+1)+b_c)$；
- 交互权重 $C_{ui} = R_{ui}(\eta_i + (1-\eta_i) q_{ui})$（式 12）。

**(6) 共享图学习上下文与联合归一化**
- 邻接矩阵 $A = \begin{bmatrix} 0 & C \\ C^\top & \bar{S} \end{bmatrix}$（式 13）；
- 联合归一化 $\hat{A} = D^{-1/2} A D^{-1/2}$，$D_{jj} = \sum_u C_{uj} + B^s_j$ 同时包含交互强度与语义预算（式 14）。

**(7) 协同–语义组合传播（CSCP）**
- 用户更新：$H_U^{(\ell+1)} = \hat{C} H_I^{(\ell)}$（式 15）；
- 物品更新：$H_I^{(\ell+1)} = \hat{C}^\top H_U^{(\ell)} + \hat{S} H_I^{(\ell)}$（式 16）——同时聚合交互与语义消息；
- **联合执行**：$H^{(\ell+1)} = \hat{A} H^{(\ell)}$（式 17），单次稀疏乘法完成，避免关系输出物化与融合；
- **深度聚合**：$\bar{H} = \frac{1}{L+1} \sum_{\ell=0}^{L} H^{(\ell)}$（式 18）。

**(8) 预测与优化**
- 内积打分 $\hat{y}_{ui} = \bar{h}_u^\top \bar{h}_i$（式 19）；

### 2.3 理论分析

- **命题 A.1**：共享状态读出可分解为 $K_L = K_c + K_s + K_{mix}$，分别对应纯协同、纯语义与跨关系组合路径；

- **命题 A.4**：Joint 与 R2（关系分离执行后求和）在精确算术下产生相同层状态、读出与参数梯度；
