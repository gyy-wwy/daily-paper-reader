## 摘要
尽管大语言模型（LLM）已被应用于推荐系统，但主流方法大多对单一类型的行为（例如浏览或购买）进行建模。即便纳入多种行为，现有方法也将异构动作展平为同质的 token 序列，忽视了它们在决策中的不同作用。这种展平无法捕捉复杂决策中的语义层级与语境细微差别，例如价格与质量之间的权衡。因此，在涉及高度相似物品的关键“困难选择”场景中，性能会下降。为弥合这一差距，我们提出 MARI（Memory-Augmented Recommendation with Interpretability），将预测建立在显式、结构化的决策证据之上。MARI 维护一个决策记忆库（DMB），将用户过去的决策依据存档为结构化决策记忆（SDM）：对目标、约束和权衡的简洁记录。这些 SDM 通过事后决策蒸馏（Post-Hoc Decision Distillation）从异构行为和用户生成内容中离线生成。通过检索相关 SDM 来增强 LLM 推理，MARI 实现了可解释性与可扩展性，同时避免了处理长原始序列的高昂成本。大量实验表明，MARI 在标准的下一项预测和新提出的困难选择预测（Difficult Choice Prediction）任务上显著优于最先进的基线，并通过将记忆构建与在线推理解耦，带来较低的延迟开销。定性分析揭示了对用户决策的可操作、人类可读的洞察，标志着迈向推理感知推荐系统的具体一步。

## Abstract
Despite the adoption of large language models (LLMs) in recommendation systems, prevailing approaches mostly model single-type behaviors (e.g., views or purchases). Even when incorporating multiple behaviors, existing methods flatten heterogeneous actions into homogeneous token sequences, ignoring their distinct decision-making roles. This flattening fails to capture semantic hierarchies and contextual nuances in complex decision-making, such as trade-offs between price and quality. Consequently, performance degrades in critical ``difficult-choice'' scenarios involving highly similar items. To bridge this gap, we propose MARI (Memory-Augmented Recommendation with Interpretability), which grounds predictions in explicit, structured decision evidence. MARI maintains a Decision Memory Bank (DMB) that archives users' past rationales as Structured Decision Memories (SDMs): concise records of goals, constraints, and trade-offs. These SDMs are generated offline via Post-Hoc Decision Distillation from heterogeneous behaviors and user-generated content. By retrieving relevant SDMs to augment LLM reasoning, MARI achieves interpretability and scalability without the prohibitive cost of processing long raw sequences. Extensive experiments show MARI significantly outperforms state-of-the-art baselines on standard next-item prediction and a newly introduced Difficult Choice Prediction task, incurring low latency overhead by decoupling memory construction from online inference. Qualitative analyses reveal actionable, human-readable insights into user decision-making, marking a concrete step toward reasoning-aware recommendation systems.

## 2. 方法论

- **核心思想**：两阶段框架，解耦离线决策知识构建与在线推荐推理。
  - 离线：通过事后决策蒸馏 PHDD，从异构行为与用户生成内容中生成结构化决策记忆 SDM，构建决策记忆库 DMB。
  - 在线：检索相关 SDM 增强 LLM 推理，输出推荐结果与可读解释。

- **决策记忆库 DMB**：
  - 类别感知构建：每个用户在每个商品类别下维护记忆，避免跨类别规则被稀释。
  - 每条记录包含检索嵌入、SDM 文本与时间戳。
  - SDM 为五元组：
    - 决策意图推理 R：自然语言解释购买原因。
    - 决策画像标签 T：如品牌敏感、价格敏感、认证驱动。
    - 决策效率 E：flash / rapid / considered / prolonged。
    - 决策偏好因素 P：正权重属性键值对，如品牌=Nike、价格=500–800。
    - 决策规避因素 A：被拒绝属性键值对，如材质=polyester、价格>1200。
  - 标签和因素键来自闭集词表，通过 LLM 迭代聚类得到。

- **事后决策蒸馏 PHDD**：
  - 教师模型：DeepSeek-R1，基于购前异构行为序列生成 CoT 与结构化 SDM。
  - 特权信息：购后评论仅用于教师校准，不泄漏给学生训练与推理。
  - 学生模型：Qwen3-4B，全参数微调，通过 CoT 蒸馏学习教师推理轨迹与最终 SDM。
  - 训练目标：最小化学生生成 token 与教师 CoT + SDM 文本的交叉熵。
  - 检索嵌入：用冻结的 Qwen3-Embedding-0.6B 编码购前行为序列，存入 FAISS 向量库。

- **在线推理与检索**：
  - 近期行为编码为查询向量。
  - NIP：目标类别未知，跨类别按行为相似度检索 Top-K SDM。
  - DCP：目标类别已知，类别内按时间最近检索 Top-K SDM；若无该类记忆则回退到相似度检索。
  - 默认 K=3，将检索到的 SDM 与近期行为拼接为 prompt，增强 LLM 推理。
  - 部署模式：
    - Plug-and-Play：免训练增强现有 LLM 推荐器。
    - CoT-Distilled：微调专用学生模型，同时输出预测与理由。

## 7. 优点

- **显式决策建模**：用 SDM 记录目标、约束、偏好与规避因素，超越“行为序列”层面。
- **可解释性强**：推荐理由可追溯到检索到的历史决策记忆，支持人类可读解释。
- **可扩展与低延迟**：离线构建 DMB，在线仅检索 Top-K 记忆，避免处理超长原始序列。
- **多行为语义利用**：区分 search、

- **类别感知记忆组织**：按用户—类别维护决策记忆，降低跨类别规则干扰，使偏好、约束与规避因素在具体决策域内更精确。

  - 在公开基准上建立可复现的决策记忆评测协议。

## 10. 总体评价

MARI 的核心贡献在于把推荐中的隐式行为模式转化为显式、结构化、可检索的决策记忆，并通过事后蒸馏与检索增强生成，将离线决策知识低成本地注入在线 LLM 推荐。其方法设计清晰，兼顾可解释性、可扩展性与困难选择能力；实验覆盖多任务、多模型规模、消融与鲁棒性分析，结论具有较强启发性。但论文仍受限于私有数据、离线评估、算力未披露与 LLM 评估主观性，实际部署中的隐私、时效、冷启动与偏差问题需要进一步研究。总体而言，这是一项将结构化决策建模与 LLM 推荐相结合的前沿工作，为后续“推理感知推荐系统”提供了有价值的方向。
