## 摘要
图协同过滤模型在推荐系统中取得了显著成功。然而，在严格冷启动场景下，由于未观测物品的拓扑隔离，它们本质上会遭遇灾难性的表示坍缩。尽管融合多模态语义特征提供了一种潜在补救措施，但将孤立的语义属性直接映射到全局拓扑驱动的协同空间，往往会引发表示退化与优化冲突。为弥合这一根本性结构鸿沟，我们提出了 DualGCN，一种创新的双分支图知识蒸馏框架。在解耦的两阶段训练范式下，DualGCN 首先构建一个鲁棒的协同教师网络，其中物品表示由拓扑平滑的语义先验锚定，从而有效重塑潜在流形。随后，一个语义学生分支采用残差映射机制和幅度无关的余弦蒸馏目标，在不破坏已建立的协同信号的情况下实现高保真跨模态对齐。此外，我们引入动态范数重建机制，以在全局检索过程中严格校准新物品和热物品的物理尺度。在三个真实世界基准数据集上的大量实验表明，DualGCN 在严格冷启动场景中显著优于最先进的基线，同时全面保持了对高活跃物品的推荐准确率。

## Abstract
Graph Collaborative Filtering models have achieved remarkable success in recommendation systems. However, they inherently suffer from a catastrophic representation collapse in strict cold-start scenarios due to the topological isolation of unobserved items. While integrating multi-modal semantic features offers a potential remedy, directly mapping isolated semantic attributes into a globally topology-driven collaborative space frequently precipitates representation degradation and optimization conflicts. To bridge this fundamental structural divide, we propose DualGCN, an innovative Dual-Branch Graph Knowledge Distillation Framework. Operating under a decoupled two-stage training paradigm, DualGCN first constructs a robust collaborative teacher network where item representations are anchored by a topology-smoothed semantic prior, effectively reshaping the latent manifold. Subsequently, a semantic student branch employs a residual mapping mechanism and a magnitude-agnostic cosine distillation objective to achieve high-fidelity cross-modal alignment without disrupting established collaborative signals. Furthermore, we introduce a dynamic norm reconstruction mechanism to rigorously calibrate the physical scales of novel and warm items during global retrieval. Extensive experiments across three real-world benchmark datasets demonstrate that DualGCN significantly outperforms state-of-the-art baselines in strict cold-start scenarios while comprehensively preserving recommendation accuracy for highly active items.

## 2. 方法论：核心思想、关键技术细节与算法流程

- **核心思想**：
  - 采用**非对称双分支架构**：协同教师分支学习拓扑协同信号，语义学生分支学习从语义到协同空间的映射；
  - 使用**解耦两阶段训练**，避免拓扑更新与语义对齐的梯度冲突；
  - 通过**拓扑平滑语义先验**锚定协同空间，通过**残差映射 + 余弦蒸馏**实现跨模态对齐；
  - 推理时用**动态范数重构**统一冷热物品的向量尺度。

- **语义先验构造**：
  - 将物品名称与类别拼接为文本描述 \(t_i\)，用预训练语言模型 `all-mpnet-base-v2` 编码为 768 维向量；
  - 经 PCA 投影到与协同嵌入一致的 \(d=64\) 维，得到语义向量 \(s_i\)；
  - 对 \(s_i\) 做 L2 归一化得 \(\bar{s}_i\)，并全程冻结，不参与反向传播。

- **协同教师分支**：
  - 热物品第 0 层初始化为 ID 嵌入与语义锚的融合：\(e_i^{(0)} = e_i + \gamma \bar{s}_i\)，其中 \(\gamma\) 为可学习标量，控制语义注入强度；
  - 用户侧仅保留 ID 嵌入：\(e_u^{(0)} = e_u\)；
  - 按 LightGCN 方式执行 \(K\) 层对称归一化消息传递，并做逐层平均聚合，得到教师表征 \(\tilde{e}_i^T\)；
  - 矩阵形式中，教师表征可分解为“图传播的 ID 嵌入”与“拓扑平滑语义先验”两部分，后者使物品语义沿交互边扩散到用户表示中。

- **语义学生分支**：
  - 仅依赖冻结语义先验 \(\bar{s}_i\)，通过 MLP 预测协同空间中的偏差；
  - 采用残差形式：\(\tilde{e}_i^S = \text{MLP}(\bar{s}_i) + \gamma \bar{s}_i\)，以语义方向为锚，学习非线性拓扑偏差；
  - 该设计避免从孤立语义直接深映射到全局协同空间造成的表示退化。

- **两阶段优化**：
  - **第一阶段：协同教师预训练**
    - 冻结学生网络参数 \(\{W_1,W_2,b_1,b_2\}\)；
    - 激活用户/物品 ID 嵌入与 \(\gamma\)，仅优化第 0 层嵌入；
    - 使用 BPR 损失：\(\mathcal{L}_{BPR} = -\sum \ln \sigma(\hat{y}_{ui}-\hat{y}_{uj}) + \lambda \|\Theta\|^2\)，其中 \(\hat{y}_{ui}=(\tilde{e}_u^T)^\top \tilde{e}_i^T\)。
  - **第二阶段：跨空间蒸馏对齐**
    - 永久冻结第一阶段收敛的 \(\{e_u,e_i,\gamma\}\)；
    - 教师最终表征 \(\tilde{e}_i^T\) 作为静态软标签，仅训练学生映射网络；
    - 使用**双侧归一化余弦蒸馏损失**：\(\mathcal{L}_{distill}=1-\frac{1}{|I_{warm}|}\sum_i \frac{(\tilde{e}_i^S)^\top \tilde{e}_i^T}{\|\tilde{e}_i^S\|_2\|\tilde{e}_i^T\|_2}\)；
    - 论文指出 MSE 会引入绝对幅度约束，InfoNCE 会引入负样本斥力，均不如余弦蒸馏。

- **动态范数重构与自适应推理**：
  - 计算教师分支热物品表征的平均 L2 范数 \(\mu_{norm}\)；
  - 根据物品实时度数 \(d_i\) 与阈值 \(\tau\) 路由：
    - 若 \(d_i \ge \tau\)，直接使用教师表征 \(\tilde{e}_i^T\)；
    - 若 \(d_i < \tau\)，使用学生单位方向向量乘以 \(\mu_{norm}\) 进行尺度校准；
  - 最终用户-物品偏好分数为 \(\hat{y}_{u,i}=(\tilde{e}_u^T)^\top e_i^*\)；
  - 该机制无需额外训练开销，旨在消除冷热物品因幅度不统一导致的检索偏差。

- **复杂度**：
  - 训练每轮时间复杂度约 \(O(K|E|d)\)，空间复杂度约 \(O(|V|d+|E|)\)，保持与 LightGCN 类似的线性可扩展性。
