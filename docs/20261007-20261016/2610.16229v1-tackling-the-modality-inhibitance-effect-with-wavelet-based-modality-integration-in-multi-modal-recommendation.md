## 摘要
利用丰富的模态特征近来在多模态推荐系统（MRSs）中日益受到关注。为了刻画用户的模态偏好，现有工作主要关注模态融合，可通过注意力求和或拼接来实现。在本工作中，我们提出模态抑制效应——一种限制现有 MRSs 的现象：当这些模型从双模态配置转向三模态配置时，会导致显著的性能下降。具体而言，除了新引入模态中固有的模态特定污染外，新特征的加入还导致过度的信息冗余，从而严重阻碍当前方法中的有效融合。为解决模态抑制效应，我们提出一种新的多尺度模态小波（MMWave）多模态推荐器，旨在充分利用关键模态特征并抑制模态特定噪声。这是通过从多尺度（时域和频域）视角采用小波分解来实现的，确保仅提取每个模态的关键（非冗余）特征。随后，我们通过设计一个新的结构感知多模态图学习模块来考虑物品模态特征之间的潜在关联，该模块捕获与物品相关的高阶潜在结构信息。为了调节模态特征的相对贡献并实现有效融合，我们进一步提出一个新的自适应模态调节器组件，其采用一种新的交叉权重融合策略。在四个真实世界数据集上进行的实验验证了所提模型的有效性。本工作的源代码已在 https://github.com/kennethorq/MMWave 公开。

## Abstract
Harnessing rich modality features has recently gained prominence in multi-modal recommendation systems (MRSs). To delineate user modality preferences, existing works focus on modality fusion, which can be achieved via attentive summation or concatenation. In this work, we introduce the modality inhibitance effect - a phenomenon which limits existing MRSs when these models transit from dual-modal to tri-modal configurations resulting in significant performance degradation. In particular, apart from the modal-specific contamination encapsulated in the newly introduced modality, the inclusion of new features results in excessive informational redundancy, thereby severely impeding effective integration within current approaches. To address the modality inhibitance effect, we propose a new multi-scale modality wavelet (MMWave) multi-modal recommender, which aims to fully capitalize on essential modality features and suppress modal-specific noise. This is acheived by employing wavelet decomposition from a multi-scale (time \& frequency) perspective, ensuring that only essential (non-redundant) features of each modality are extracted. We then account for the latent associations between item modality features by designing a new structure-aware multi-modal graph learning module that captures high-order latent structural information pertaining to items. To modulate the relative contributions of modality features and achieve effective integration, we then propose a new adaptive modality regulator component that employs a new cross-weight integration strategy. Experiments conducted on four real-world datasets validate the efficacy of our proposed model. The source code for this work has been made publicly available at https://github.com/kennethorq/MMWave.
