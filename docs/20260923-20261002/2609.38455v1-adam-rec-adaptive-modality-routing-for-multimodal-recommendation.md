## 摘要
尽管近年来的多模态推荐系统已证明引入视觉和文本信息能够提升下游性能，但现有方法大多依赖静态模态融合，假设文本与视觉信号的相对重要性在不同推荐场景中保持稳定。这种设计可能未能充分考虑不同推荐请求之间的重要差异：有些查询需要细粒度的视觉线索，而另一些查询则更适合由文本或功能语义来满足；在这种情况下，不加区分的模态融合会引入无信息线索并损害推荐质量。为此，我们提出 AdaM-Rec，一个基于 LLM 的多模态推荐自适应模态路由框架，能够针对特定用户查询动态校准对文本证据和多模态证据的依赖程度。它建立在物品与用户偏好的结构化自然语言表示之上，利用代理召回任务估计模态可靠性。具体而言，它生成与实际查询粒度相匹配的伪查询，并将用户有过正向交互的物品作为可验证的代理目标，评估哪种模态在类似场景中能取得更好的召回性能，并以智能体方式优化路由策略。随后，它使用优化后的策略执行路由召回，利用协同物品丰富结果，并根据候选与查询及用户偏好的相关性进行排序。实验表明，AdaM-Rec 相较于最先进的基线方法表现强劲，凸显了在多模态推荐中自适应控制模态依赖的有效性与更广泛潜力。

## Abstract
While recent multimodal recommender systems have demonstrated the effectiveness of incorporating visual and textual information to improve downstream performance, most existing methods rely on static modality fusion, assuming that the relative importance of textual and visual signals remains stable across recommendation scenarios. This design may not fully account for an important variation across recommendation requests: some queries require fine-grained visual cues, whereas others are better served by textual or functional semantics, in which case indiscriminate modality fusion brings in uninformative cues and impairs recommendation quality. To address this, we propose AdaM-Rec, an LLM-based framework for adaptive modality routing in multimodal recommendation, which enables dynamic calibration of reliance on textual and multimodal evidence for user-specific queries. Built on structured natural-language representations of items and user preferences, it estimates modality reliability using proxy recall tasks. Specifically, it generates pseudo-queries that match the granularity of the actual query while pointing to the user's positively interacted items as verifiable proxy targets, evaluating which modality yields better recall performance in analogous scenarios and optimizing the routing strategy in an agentic manner. It then performs routed recall with optimized strategy, enriches results with collaborative items, and ranks candidates by their relevance to both the query and user preferences. Experiments demonstrate that AdaM-Rec delivers strong performance against state-of-the-art baselines, highlighting the effectiveness and broader potential of adaptive control over modality reliance in multimodal recommendation.

## 2. 方法论

### 2.1 核心思想

- 不假设视觉信息总是有益，而是为每个用户查询动态校准文本召回与多模态召回的权重和预算。
- 利用用户历史正反馈物品作为**可验证代理目标**：实际查询目标未知，但历史正反馈物品已知，可构造伪查询来评估哪种模态在类似场景下更可靠。
- 通过 LLM 策略进行**智能体式路由优化**，并融合协同知识、候选召回增强和偏好感知排序。

### 2.2 离线：多模态物品画像与用户建模

- **物品画像**：
  - 对每个物品 \(i=(v_i,l_i)\)，用 MLLM \(\phi_M\) 和 profiling prompt 提取结构化文本画像 \(s_i\)。
  - 同时计算文本嵌入 \(e^{txt}_i=E_{txt}(l_i)\) 和多模态嵌入 \(e^{mm}_i=E_{mm}(v_i,l_i)\)。
  - 构建物品数据库 \(D_{item}=\{(s_i,e^{txt}_i,e^{mm}_i)\}\)。
- **用户偏好建模**：
  - 用户历史序列 \(u=\{(i^u_t,b^u_t)\}\)，映射为历史行为画像 \(h_u=\{(s^u_t,b^u_t,t)\}\)。
  - 用 LLM 策略 \(\phi_L\) 和偏好建模 prompt 推断结构化偏好 \(p_u\)，分为 `strong_pref`、`nice_to_have`、`dislike`。
  - 写入用户偏好数据库 \(D_{pref}=\{h_u,p_u,e^{pref}_u\}\)，其中 \(e^{pref}_u=E_{txt}(p_u)\)。
- **协同建模**：
  - 计算用户偏好嵌入余弦相似度，取 top-\(K_c\) 相似用户 \(N_u\)。
  - 协同知识为 \(C_u=\{(\theta_v,s_v,b_v)\}_{v\in N_u}\)，包括相似用户先前优化的路由参数、历史物品和行为标签。

### 2.3 自适应模态路由

- **协同先验初始化**：
  - LLM 策略基于协同知识 \(C_u\) 和初始化 prompt \(P_{pi}\)，估计初始路由状态：
    \[
    \theta^{(0)}_u=(\alpha^{(0)}_u,\beta^{(0)}_u,K^{(0)}_u)=\phi_L(C_u,P_{pi})
    \]
  - 其中 \(\alpha\) 为文本召回权重，\(\beta\) 为多模态召回权重，\(\alpha+\beta=1\)，\(K\) 为召回预算，且 \(K\le\tau\)。
- **基于历史交互的自优化**：
  - 给定实际查询 \(q\)，LLM 用改写 prompt \(P_{rw}\) 生成一组历史对齐伪查询：
    \[
    \tilde{Q}_u=\phi_L(q,h_u,P_{rw})=\{\tilde{q}_1,\dots,\tilde{q}_{T_f}\}
    \]
  - 每个伪查询与真实查询粒度相似，但指向用户已知正反馈历史物品；无关或负反馈历史物品被过滤。
  - 对每个伪查询分别执行文本召回和多模态召回，获得目标历史物品排名 \(r^{(t)}_{txt}\) 和 \(r^{(t)}_{mm}\)。
  - LLM 根据排名、记忆 \(M^{(t-1)}_u\) 和路由 prompt \(P_{mr}\)，推断下一状态：
    \[
    (\theta^{(t)}_u,z^{(t)}_u)=\phi_L(r^{(t)}_{txt},r^{(t)}_{mm},M^{(t-1)}_u,P_{mr})
    \]
  - 每轮结果写入记忆：\(M^{(t)}_u=M^{(t-1)}_u\cup\{(r^{(t)}_{txt},r^{(t)}_{mm},\theta^{(t)}_u,z^{(t)}_u)\}\)。
  - 最终路由参数 \(\theta_u=\theta^{(T)}_u\)，并写回用户偏好库，供其他用户作为协同知识复用。
