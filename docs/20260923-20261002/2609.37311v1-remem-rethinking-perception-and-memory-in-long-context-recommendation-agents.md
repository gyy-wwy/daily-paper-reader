## 摘要
近期的推荐智能体（RecAgents）通过将推荐转变为一种主动的、用户侧范式，提供了一种有前景的替代方案；在该范式中，生成式智能体自主感知外部平台、对用户偏好进行推理并执行决策。然而，现有 RecAgents 仍受制于两个关键局限：基于噪声且异构的物品页面的脆弱物品感知，以及对扩展用户历史和多步交互轨迹的低效长上下文推理。为应对这些挑战，我们提出了一种新的推荐智能体框架，称为 ReMem，它将基于 OCR 的多模态感知与随时间演化的动态记忆相结合。ReMem 不解析原始 HTML，而是通过截图观察物品页面，并借助 OCR 工具提取结构化的多模态信息，从而实现更具拟人化且与平台无关的感知机制。为支持长时程偏好建模，ReMem 进一步引入了分块式顺序记忆更新策略；在该策略中，智能体有选择地维护一个固定大小的、由信息量丰富的历史交互组成的记忆，同时以线性推理复杂度和有界上下文长度处理任意长的上下文。这一设计使智能体能够在不依赖外部记忆模块、也不干扰标准自回归生成过程的情况下，保留不断演化的用户偏好。为增强动态记忆指令，我们进一步提出了一种多记忆 GRPO 变体，它将最终答案的优势传播到所有对最终响应有贡献的中间对话。在三个数据集上的大量实验表明，ReMem 持续优于最先进的基线，在搜索、排序和评判这三个推荐智能体任务上平均提升 5.16%。

## Abstract
Recent Recommendation Agents (RecAgents) offer a promising alternative by shifting recommendation to an active, user-side paradigm, where generative agents autonomously perceive external platforms, reason over user preferences, and execute decisions. However, existing RecAgents still suffer from two critical limitations: brittle item perception based on noisy and heterogeneous item pages, and inefficient long-context reasoning over extended user histories and multi-step interaction traces. To address these challenges, we propose a novel recommendation agent framework, termed as ReMem, that combines OCR-based multimodal perception with time-evolving dynamic memory. Instead of parsing raw HTML, ReMem observes item pages through screenshots and extracts structured multimodal information via an OCR tool, enabling a more humanoid and platform-agnostic perception mechanism. To support long-horizon preference modeling, ReMem further introduces a chunk-wise sequential memory update strategy, where the agent selectively maintains a fixed-size memory of informative historical interactions while processing arbitrarily long contexts with linear inference complexity and bounded context length. This design allows the agent to preserve evolving user preferences without relying on external memory modules or disrupting the standard autoregressive generation process. To enhance the dynamic memory instruction, we further develop a multi-memory GRPO variant, which propagates the final-answer advantage to all intermediate conversations that contribute to the final response. Extensive experiments on three datasets demonstrate that ReMem consistently outperforms state-of-the-art baselines, achieving an average improvement of 5.16\% across three recommendation agent tasks, namely searching, ranking, and judging.

# ReMem 论文总结

## 1. 核心问题与研究动机

- **背景**：LLM 驱动的推荐系统在传统平台侧部署中面临大规模 token 消耗与高延迟瓶颈。研究者转向**主动式、用户侧**的推荐智能体（RecAgents）范式：用户表达开放式目标，智能体自主感知外部平台、推理偏好并执行决策。
- **两大核心局限**：
  - **脆弱的物品感知**：现有 RecAgents 主要依赖解析原始 HTML，在异构平台布局下易失败，丢失多模态细节，并引入广告/跟踪脚本等噪声。
  - **低效的长上下文推理**：多步动作、复杂推理链与长期交互历史产生海量 token，超出 LLM 上下文窗口；现有方案（token 级压缩、外部记忆插件、向量检索）存在分布外泛化差、需辅助模块、破坏标准自回归生成等问题。
- **核心追问**：RecAgent 如何像人一样"看"物品页，并像人一样"有选择地记忆"演化偏好？
- **两项人类直觉**：
  - **感知**：网页界面为人类视觉优化，人类通过视觉扫描而非解析 HTML。
  - **记忆**：人类处理长期信息时动态抽象关键概念、丢弃冗余，以有限认知容量完成长时程任务。

## 2. 方法论

### 2.1 整体框架（ReMem）
由三部分组成：(a) 基于 OCR 的多模态感知；(b) 时间演化记忆（TEM）；(c) Multi-Memory GRPO 训练。

### 2.2 OCR 多模态感知
- 放弃原始 HTML，通过**截图 + DeepSeek-OCR-2** 解析物品页（文本、图像、图表、交互元素）。
- OCR 模块由编码器（将页面离散化为视觉 token）与解码器（条件生成输出）组成，输出嵌入"物品卡片"自然语言模板，供 LLM 主干推理。
- 形式化：`v_j = OCR(Request(url(texts, images, charts)))`
- 优势：平台无关、拟人化、过滤广告等噪声。

### 2.3 时间演化记忆（TEM）
- **核心思想**：将任意长用户交互历史视为**顺序证据流**，维护一个固定长度、随时间更新的紧凑记忆，而非单体长上下文。
- **两阶段流程**：
  - **上下文处理**：按窗口 W 将历史 H={v_1,...,v_J} 切分为 T 个连续块 C={c_1,...,c_T}，每块结合前一步记忆生成新记忆：`m_t ~ p_θ(m_t | m_{t-1}, c_t, Q)`，记忆长度固定为 L，且**覆盖式更新**。
  - **答案生成**：所有块处理完后，仅基于任务输入、候选物品 OCR 结果和最终记忆生成推荐：`y ~ p_θ(y | ĉ, m_T, Q)`。
- **理论推导**：将长历史似然分解为对潜在记忆状态的边缘化，其中"看"（见块）与"记"（更新记忆）交替；记忆更新路径按 token 逐级分解，等价于将 Transformer 解码器转化为**状态大小受控的循环偏好更新器**。
- **复杂度**：每步活跃上下文上界 O(C+L)，处理 T 块总复杂度 O(T(C+L)²)；由于 N≈TC 且 C、L 固定，整体**关于历史长度线性** O(N)，而直接全历史注意力为 O(N²)。
- **优点**：支持无界历史、缓解长上下文性能悬崖、线性成本；记忆以**自然语言 token** 显式表示，可检查、调试、编辑、受 prompt 约束。

### 2.4 Multi-Memory GRPO
- **问题**：单次查询产生多个**上下文独立**的中间记忆对话，无法像标准多轮工具调用那样用统一 attention mask 分配信用。
- **生成**：策略模型基于 (m_{t-1}, c_t, Q) 生成 T 个顺序记忆实例 M={m_1,...,m_T}，再基于 m_T 生成最终答案；采样 G 组完整推理实例（高温度 1.5）。
- **奖励**：仅用最终答案的推荐指标（Accuracy/HR/Ranking Score）计算 `r_g = r(y_g, y+)`，组内归一化得到优势 `A_g`。
- **关键修改**：将最终答案优势 `A_g` **传播到所有中间记忆摘要**，强化导致高质量答案的记忆。
- **记忆级策略比**：每个记忆仅条件于原查询、对应块及自身前序 token，避免跨记忆人为信用分配。
- **目标函数**：`J_Mem-GRPO(θ) = J_Ans(θ) + λ·J_Mem(θ)`，二者均采用 PPO 式裁剪目标（δ=0.2），`J_Mem` 受 λ 控制；另加记忆 token 的 KL 正则（β=0.04）。
- **奖励建模**：`r_g = r_format + r_correct`，格式奖励最高 1.5 分（XML 标记计数、软格式、严格格式），正确性用任务指标。

- **对比基线（四类）**：

  - 语言辅助推荐：P5、TokenRec
  - 推荐智能体：ToolRec、iAgent
  - 长上下文 LLM 智能体：QwenLong-L1、Mem0

## 6. 主要结论与发现

- **Pilot Study 发现**：
  - OCR 感知显著优于 HTML 解析和截图输入（WebWalkerQA 上 4B/9B 平均从 ~50% 提升至 ~58%），但加重长上下文推理负担。
  - 动态记忆在 HotpotQA 长上下文（至 3.5M token）上展现**近乎无损的长度外推**，优于长上下文专用模型、向量记忆和截断策略。
- **主实验结论**：
  - ReMem 在搜索和判断任务上全面最优，排序任务 3 个中 2 个最优；平均超越最强基线 **5.16%**，统计显著（p<0.01）。
  - 仅扩展上下文窗口或粗略记忆（Qwen-L1、Mem0）**不保证**推荐性能提升，如 MovieTV 排序 Mem0（0.3269）低于 iAgent（0.3817）。
  - 变长推理中，ReMem 长上下文性能可与若干基线中上下文性能相当甚至更优。
- **消融结论**：移除 TEM 造成最大性能下降，说明有效记忆机制是关键；即使无 GRPO 后训练也优于 SOTA 基线。
- **超参数结论**：W=3 在 Games/MovieTV 最优，更长历史的 Books 偏好 W=4–5，最优块大小与平均历史长度正相关。

## 7. 优点

- **范式创新**：首次在 RecAgent 中联合探索 OCR 多模态感知与 RL 增强的动态记忆，将"如何看"与"如何记"统一重新审视。
- **感知设计合理**：借助网页为人类视觉设计的特性，OCR 截图感知平台无关、过滤噪声、保留多模态信息，契合真实用户浏览行为。
- **记忆机制简洁高效**：显式 token 空间记忆，无需外部模块、KV cache 操作或架构修改，保持标准自回归生成，支持并行化；理论证明线性复杂度与有界上下文。
- **可解释性强**：记忆为人类可读自然语言，可检查、调试、编辑、prompt 约束。
- **训练方法针对性强**：Multi-Memory GRPO 巧妙解决"独立生成、后聚合"记忆的信用分配问题，将最终答案优势传播至所有中间记忆。
- **实验较全面**：多数据集、多任务、多基线类别、消融、变长、超参、延迟、案例齐备，含统计显著性检验与多次重复。

## 8. 不足与局限

- **推理延迟显著**：ReMem 每样本 98–225 s，远高于原始 LLM（3.6–9.8 s），作者承认存在不可忽视的开销，仅在"主动推荐"场景下可接受，**不适合严格实时场景**。
- **未全部最优**：MovieTV 排序任务上落后 iAgent（-2.59%），说明方法并非在所有设置下占优。
- **OCR 依赖风险**：整体性能高度依赖 DeepSeek-OCR-2 的质量，文中 TODO 提及尚未系统评估不同 OCR 模型、失败率与跨平台表现。
- **基线对比公平性**：部分基线训练/输入设置不对等（如 SASRec 仅用 ID、QwenLong-L1 零样本），可能高估优势。
- **训练细节缺失**：未报告训练时长、总算力开销、收敛曲线等关键可复现信息。
- **领域覆盖有限**：仅基于 Amazon 三领域数据，未验证跨平台/跨语言/真实在线环境；用户行为建模局限于浏览、比较、购买等常见动作，未涵盖搜索、结账等更细粒度行为（作者列为未来工作）。
- **算力门槛**：四块 H20 + GRPO 训练，复现成本较高。
- **消融范围有限**：消融仅在 Searching 任务上报告，未覆盖 Ranking/Judging。
