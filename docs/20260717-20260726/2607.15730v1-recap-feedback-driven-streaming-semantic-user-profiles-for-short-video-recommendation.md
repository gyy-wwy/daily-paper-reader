## 摘要
基于语言的用户画像将长期行为历史转换为显式的语义表示用于推荐。然而，大多数画像生成器是在开环中优化的：它们可以流畅地总结过去行为，但未直接训练以改进未来推荐。我们在真实世界的短视频推荐中研究这个问题，其中用户行为连续到达为流，并且画像必须在有限容量下增量更新。这要求维护一致的有界画像状态，并从工业隐式行为日志中构建画像目标的语义反馈。我们提出RECAP，一个离线闭环框架，用于使用历史推荐反馈优化流式结构化语义画像。RECAP通过将基于LLM的语义更新与确定性的生命周期和容量控制相结合，将每个画像维护为有界结构化记忆。RECAP通过使用LLM判断器过滤标签一致的行为对，并训练双塔评估器（其匹配分数作为GRPO奖励）来构建画像目标的语义反馈。在快手短视频数据上的实验表明，RECAP在基础生成器上改进了uAUC 0.0084和Recall@2000约4.9%。进一步分析证实了反馈构建和策略优化的益处，并展示了画像更新中更扎实的细化和用户级抽象。为期七天的在线A/B测试进一步显示，每位用户的平均应用使用时间统计显著提高了0.139%。

## Abstract
Language-based user profiles convert long behavioral histories into explicit semantic representations for recommendation. However, most profile generators are optimized in an open loop: they may summarize past behavior fluently, but are not directly trained to improve future recommendation. We study this problem in real-world short-video recommendation, where user behaviors continuously arrive as streams and profiles must be incrementally updated under limited capacity. This requires maintaining a consistent bounded profile state and constructing profile-targeted semantic feedback from industrial implicit behavior logs. We propose RECAP, an offline closed-loop framework for optimizing streaming structured semantic profiles with historical recommendation feedback. RECAP maintains each profile as a bounded structured memory by combining LLM-based semantic updates with deterministic lifecycle and capacity control. RECAP constructs profile-targeted semantic feedback by filtering label-consistent behavior pairs with an LLM judge and training a dual-tower evaluator whose matching score serves as a GRPO reward. Experiments on Kuaishou short-video data show that RECAP improves uAUC by 0.0084 and Recall@2000 by about 4.9% over the base generator. Further analyses confirm the benefits of feedback construction and policy optimization, and show more grounded refinement and user-level abstraction in profile updates. A seven-day online A/B test further shows a statistically significant 0.139% improvement in average application usage time per user.

## 1. 核心问题与整体含义（研究动机和背景）

- **研究背景**：基于语言的用户画像（language-based user profiles）将用户长期行为历史转换为显式语义表示，用于推荐系统。但现有画像生成器大多在“开环”中优化：它们能够流畅地总结过去行为，却未直接训练以改进未来推荐。
- **实际问题**：在工业短视频推荐场景中，用户行为连续流式到达，画像必须在有限存储容量下增量更新。这带来两个挑战：
  1. **流式画像状态维护**：需要维护一个一致且有界的结构化状态，跨多轮更新（保留、更新、合并、删除兴趣项）。
  2. **画像目标的语义反馈构建**：工业隐式行为日志（点赞、跳过）并非直接反映语义对齐程度，需要构造高置信度的反馈信号。
- **核心意义**：将用户画像生成从一次性的摘要任务扩展为长期、结构化、可优化的流式更新任务，从而提升推荐系统的个性化效果和可解释性。

## 2. 方法论：核心思想、关键技术细节

### 2.1 核心思想
提出 **RECAP**（Recap Evolving Interests via Closed-loop Profile optimization）—— 一个离线闭环框架，用于优化流式结构化语义画像。它将 LLM 的语义理解能力与确定性的状态管理相结合，并通过推荐对齐的奖励信号优化更新策略。

### 2.2 关键组件

#### （1）结构化用户记忆（Structured User Memory）
- **画像模式**：每个用户画像包含最多 L 个结构化兴趣条目，每个条目包括：(topic, desc) 语义对 + 生命周期元数据（span, recency, strength）。
- **分解更新**：将更新函数 \( f_\theta \) 分解为：
  - **LLM 语义模块**（参数化）：输出语义差异（confirmed_interests, new_interests），附带支持的视频索引。
  - **确定性状态机**（无参数）：执行 Update / Add / Remove 操作，管理生命周期和容量控制。
- **优势**：LLM 擅长语义抽象但不擅长精确数值管理，分离后提高可靠性。

#### （2）推荐对齐奖励（Recommendation-Aligned Reward）
- **双塔语义评估器**：使用 Qwen3-Embedding-0.6B 编码渲染后的画像文本和视频字幕，训练分类头（BCE）和对比头（NCE），输出匹配分数。
- **高置信度反馈构造**：
  - 使用 LLM 判断器（Qwen3-30B-A3B）进行成对比较，计算每个样本的标签一致性分数 \( q_{cons} \)。
  - 保留 \( q_{cons} > \tau \) 的样本作为干净反馈数据。
- **奖励公式**：
  \[
  R_{\text{rec}}(\tilde{P}^t_{u,i}) = \exp(-\mathcal{L}_{\text{bce}}(\tilde{P}^t_{u,i}, \mathcal{V}_u)) + w_{\text{rec}} \cdot \Delta_{\cos}(\tilde{P}^t_{u,i}, \mathcal{V}_u)
  \]
  第一项衡量标签预测能力，第二项衡量正负视频的余弦间隔。

#### （3）GRPO 训练
- **SFT 初始化**：使用更强的教师模型（Claude Sonnet 4.5）生成 8K 演示进行监督微调。
- **并行块级 rollout**：预计算前缀画像，对每个块独立优化，降低计算开销。
- **奖励组合**：推荐对齐奖励 + 格式惩罚 \( P_{\text{fmt}} \) + 多样性惩罚 \( P_{\text{div}} \)（防止支持视频过度重叠）。
- **更新策略**：使用 GRPO（Group Relative Policy Optimization），组内归一化优势，加上 KL 散度惩罚。

## 3. 实验设计

## 6. 主要结论与发现

1. RECAP 完整模型（SFT+GRPO）在离线双塔评估中达到最佳性能：uAUC 0.7603（+0.0084 vs. Base），Recall@2000 0.0128（+4.9%）。
2. **干净反馈优于原始反馈**：GRPO-clean 在 Cleaned Eval 上显著优于 GRPO-raw，且在 Raw Eval 上也略有提升，说明过滤噪声反馈提供了更稳定的训练信号。
3. **解耦设计优于耦合设计**：LLM 仅输出语义差异，确定性状态机管理生命周期，减少了状态字段错误（尤其是跨度错误）。
4. SFT 改善画像组织（更高覆盖率和更低重复分配率），GRPO 改善画像更新和抽象（更频繁的细化和动机级描述）。
5. 在线 A/B 测试证实实际效果：人均使用时间相对提升 0.139%（统计显著）。
