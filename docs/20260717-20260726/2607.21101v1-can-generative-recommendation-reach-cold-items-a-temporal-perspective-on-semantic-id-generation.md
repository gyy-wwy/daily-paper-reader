## 摘要
基于语义ID的生成式推荐将物品表示为共享语义令牌的序列，从而实现超越孤立物品ID的令牌重组。然而，封闭世界的重组并不一定意味着时间上的开放令牌冷启动归纳，即新物品以未见过的原子令牌或弱支持的SID路径进入物品目录。在本工作中，我们重新审视了基于SID的生成式推荐，采用了一种绝对时间协议，分离已见和未见的目标，并在令牌级别诊断冷启动物品的可达性。通过已见/未见命中分析、冷启动分类法和预言前缀探测，我们展示了当前的SID模型偶尔能够触及由已观察令牌和前缀支持的未来物品，但在未见原子令牌和未支持的SID路径上表现不佳。我们进一步通过将SID生成解释为分层语义分桶来解释这一边界：早期令牌选择粗略的语义区域，而后来的令牌细化物品特定路径。这些发现表明，SID生成是组合性的但并非完全开放式的，并提出了未来在更独立的SID空间、基于评分的接口和动态文本上下文方面的研究方向。

## Abstract
Semantic-ID-based generative recommendation represents items as sequences of shared semantic tokens, enabling token recombination beyond isolated item IDs. However, closed-world recombination does not necessarily imply temporal open-token cold-start induction, where new items enter the item catalog with unseen atomic tokens or weakly supported SID paths. In this work, we revisit SID-based generative recommendation under an absolute-time temporal protocol that separates seen and unseen targets and diagnoses the cold item reachability at the token level. Through seen/unseen-hit analysis, coldness taxonomy, and oracle-prefix probing, we show that current SID-based models can occasionally reach future items supported by observed tokens and prefixes, but struggle with unseen atomic tokens and unsupported SID paths. We further explain this boundary by interpreting SID generation as hierarchical semantic bucketing: early tokens select coarse semantic regions, while later tokens refine item-specific paths. These findings show that SID generation is compositional but not fully open-ended, and suggest future directions in more independent SID spaces, scoring-based interfaces, and dynamic textual context.

## 2. 方法论

- **绝对时间滑动窗口协议**：将时间戳交互流按绝对时间划分训练、验证、测试窗口，确保测试物品严格在训练后出现，避免留一法中的时间泄漏。窗口滑动多次获取不同时间区间。
- **Token级冷度分类**：
  - **All-token-seen**：冷物品的所有SID令牌均在训练中出现。
  - **Any-token-unseen**：至少一个令牌未出现。
  - **Prefix-seen at length ℓ**：SID的前ℓ个前缀在训练中出现。
- **Oracle前缀探测**：在解码时强制给定正确的前缀（第1个或前2个令牌），观察后续令牌生成的准确率提升，从而分离粗粒度桶选择错误与细粒度路径完成失败。
- **层次化语义分桶解释**：将SID生成视为粗到细的语义桶分类：早期令牌选择粗语义区域，后续令牌细化。通过比较TIGER的令牌分布与SASRec的桶聚合评分分布（JS散度、Pearson相关系数）验证这一观点。
- **三个诊断变体**：
  - **TIGER-SID**：使用更因式化的OPQ（优化乘积量化）替代残差量化，减弱路径依赖性。
  - **TIGER-Scorer**：保留TIGER编码器但将解码替换为候选物品评分（点积），绕过严格SID生成。
  - **TIGER-Edge**：在解码器中引入交叉注意力机制，注入动态边上下文（如交互文本、时间信号）。

## 6. 主要结论与发现

- **核心发现**：在绝对时间冷启动下，TIGER对冷物品的Recall@20几乎为零（大多数据集<0.001），远低于封闭世界评估。
- **Token级诊断**：
  - All-token-seen的冷物品仍难以推荐，说明令牌可见不足以保证组合生成成功（路径依赖是关键）。
  - Any-token-unseen的冷物品完全无法命中，构成硬边界。
  - 成功命中集中在具有深层前缀支持的冷物品（如prefix-seen-c1,c2,c3），但此类物品占比极小。
- **Oracle前缀探测**：给定正确前缀后，已见物品准确率大幅提升，但冷物品提升有限，表明瓶颈在于细粒度路径完成而非粗桶选择。
- **层次语义分桶**：早期SID位置分布与SASRec桶分布高度一致（JS散度低、相关度高），后期分化，验证了粗到细的生成本质。
- **变体效果**：
  - TIGER-SID：在部分数据集上提升冷物品命中，但无法根除边界。
  - TIGER-Scorer：显著提升冷物品性能（尤其在Sports上Recall@20从0.0002→0.0139），表明评分接口可绕过解码刚性。
  - TIGER-Edge：在动态上下文丰富的数据集（WeiboDaily, WeiboTech）上效果最佳，显示上下文信号的重要性。
