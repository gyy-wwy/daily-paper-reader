## 摘要
传统推荐系统依赖潜在（密集）表示，导致其难以解释和控制。我们提出了可控且基于内容的推荐（CCBR）框架，该框架基于文本用户画像表示构建推荐。CCBR可嵌入协同过滤模型，并通过文本瓶颈引入可控性。我们证明CCBR支持基于文本和多模态的干预，使用户能够将模型引导至其偏好的方向。与现有可控推荐系统不同，CCBR直接从物品内容（图像、音频或视频）推断文本摘要。在基于图像、音频和视频的数据集上，我们证明所提框架在获得与标准（潜在表示）模型相当的模型性能的同时，通过文本提供可控的模型摘要。该模型也优于近期可控推荐系统基线TEARS。通过系统性干预，我们验证了用户引导机制的有效性。

## Abstract
Traditional recommendation systems rely on latent (dense) representations, making them difficult to interpret and control. We propose the Controllable and Content-Based Recommendations (CCBR) framework, which builds its recommendations from textual user profile representations. CCBR plugs into collaborative filtering models and introduces controllability via text bottlenecks. We show that CCBR enables text-based and multimodal interventions, allowing users to steer the model towards the directions they prefer. Different from existing controllable recommendation systems, CCBR infers the text summaries directly from item contents (images, audio or video). Across image-, audio-, and video-based datasets, we demonstrate that the proposed framework obtains competitive model performance with standard (latent-representation) models while providing controllable model summaries via text. The model also outperforms TEARS, a recent baseline for controllable recommendation systems. Through systematic interventions, we demonstrate the efficacy of the user steering mechanism.

- **整体含义**：本文提出CCBR框架，通过**文本瓶颈**将用户偏好转化为自然语言概要，并直接从多模态物品内容中推断该概要，从而兼顾推荐性能与用户可控性。

## 论文提出的方法论

- **关键技术细节与流程**：
  1. **用户概要生成**（图1步骤1）：

## 实验设计

- **数据集与场景**：三个模态，**强泛化**协议（训练、验证、测试用户不重叠）：
  - **H&M**（服装图像）：1943个物品，70201用户；使用颜色（16类）和产品类别（51类）作为可控概念。
  - **MovieLens-20M**（电影预告片视频）：11355个物品，135269用户；使用18种电影类型作为概念。
  - **Million Song Dataset (MSD)**（音乐音频）：31046个物品，166188用户；使用80个音乐标签（流派、年代、情绪）作为概念。
- **基准方法**：
  - 7种CF骨干模型（EASE, EDLAE-FR/LR, Linear-DAE, Multi-DAE, Multi-VAE, MacridVAE）。
  - 可控推荐基线 **TEARS**（仅在VAE骨干上对比，因其原文仅提供VAE结果）。
- **评估指标**：
  - 推荐准确性：NDCG@100, Recall@50, Recall@20。
  - 可控性：通过**留一移除（LOO）** 和**加一添加（AOI）** 两种编辑干预，测量推荐列表中目标概念占比的变化（Δr_c^(K)）。
- **实验数量与公平性**：
  - 在所有三个数据集上对7个CF骨干进行CCBR训练，并与原始CF性能对比。
  - 与TEARS在VAE骨干上比较，CCBR在H&M和MSD上明显优于TEARS，在ML-20M上持平或略优。
  - 额外进行了**多模态输入干预**（从未见过物品构建的新概要编辑）和**负偏好干预**（利用ML-20M的低分评分构建含“不喜欢”的概要）。实验较为充分，覆盖了主流模型和不同模态。

## 论文的主要结论与发现

1. CCBR在引入文本瓶颈后，**推荐性能与原始CF模型相比下降幅度很小**，且始终优于TEARS基线。
2. 通过系统性编辑用户概要（移除或添加概念），CCBR能**产生单调一致的推荐变化**：移除目标概念后推荐中该概念占比下降，添加后上升。证明了文本瓶颈**因果参与**推荐过程。
3. CCBR支持**多模态输入干预**：从未见过的新物品（图像/视频/音频）通过内容编码后影响推荐，可实现冷启动编辑。
4. 在MovieLens-20M上，利用**负偏好（“不喜欢”）** 语句能有效抑制目标概念，说明文本瓶颈可以传递带符号的偏好信息。

## 优点

1. **方法创新性**：首次将多模态内容直接转化为可编辑文本概要，并融入协同过滤，兼具可解释性和可控性。
2. **灵活性**：可嫁接多种CF骨干，且通过随机嵌入替换支持有历史用户和冷启动用户两种模式。
3. **实验设计扎实**：采用强泛化协议，编辑干预设计为单因素替换，可控性量化指标合理。
4. **多模态覆盖**：在服装图像、电影视频、音乐音频三种场景中验证，方法通用性强。

## 不足与局限

1. **性能损失**：尽管可控，但CCBR推荐性能普遍低于原始CF（如H&M上NDCG@100从0.262降至0.221），对某些场景可能不可接受。
2. **编辑鲁棒性**：编辑依赖外部LLM，可能产生不符合语境的修改或引入噪声；未评估多次编辑或复合编辑的效果。
3. **计算开销**：需要离线运行MLLM和LLM生成描述和概要，在线推理也需经过文本编码器，比纯CF模型慢。
4. **实验覆盖局限**：未与更先进的可控推荐方法（如概念瓶颈模型直接对比）；未进行真实用户实验验证编辑是否好用；未报告跨语言或长尾物品场景。
5. **冷启动依赖**：对于全新用户（无交互历史），虽然支持文本查询，但概要为空，需提供外部描述，系统效果取决于初始描述质量。
