## 摘要
生成式检索在大型推荐和广告系统中越来越受欢迎，但当前方法带来了实际复杂性。语义ID方法依赖于量化、可变标识符词汇表和令牌到物品的映射；基于嵌入的流程将物品编码器与查询生成器分开训练，这限制了用户-物品的对齐。我们提出EGR，一种面向推荐和广告的嵌入原生生成式检索框架。EGR使用单个共享大语言模型，从物品元数据学习物品表示，并从交互历史学习用户表示，两者位于同一嵌入空间。物品直接作为稠密向量索引，用户历史编码为稠密检索查询。联合对比训练将相关物品分组，并将查询与其目标物品对齐。我们在公开基准、工业数据和实际部署中评估了EGR。EGR在Amazon Reviews上优于已发布的基线；在Snap DPA上，它随数据规模扩展，处理冷启动物品，并从多模态输入中受益。在生产环境中，EGR带来了+2.91%的转化率提升，在简化系统设计的同时提高了检索质量和广告性能。

## Abstract
Generative retrieval is increasingly popular in large-scale recommendation and advertising systems, yet current methods introduce practical complications. Semantic-ID methods rely on quantization, mutable identifier vocabularies, and token-to-item grounding; embedding-based pipelines train the item encoder separately from the query generator, which limits user-item alignment. We propose EGR, an Embedding-Native Generative Retrieval framework for recommendation and advertising. EGR uses a single shared LLM to learn item representations from item metadata and user representations from interaction histories in one embedding space. Items are indexed directly as dense vectors, and user histories are encoded as dense retrieval queries. Joint contrastive training groups related items and aligns queries with their target items. We evaluate EGR on public benchmarks, industrial data, and live deployment. EGR outperforms published baselines on Amazon Reviews; on Snap DPA, it scales with data, handles cold-start items, and benefits from multimodal input. In production, EGR delivers a +2.91% conversion-rate lift, simplifying system design while improving retrieval quality and ad performance.

# EGR：基于共享大语言模型的嵌入原生生成式检索（详细中文总结）

## 1. 核心问题与整体含义（研究动机和背景）

- 大规模推荐和广告系统中的候选检索要求从数亿级别的动态物品库中快速选出相关子集，同时满足低延迟、高覆盖率和新物品上线速度。
- 现有生成式检索方法主要分为两类：
  - **语义ID（SID）方法**（如TIGER、PLUM）：需要量化、可变标识符词汇表、令牌到物品的映射（grounding），系统复杂，物品更新需重建标识符。
  - **基于嵌入的方法**（如PinRec）：物品编码器和查询生成器分开训练，导致物品嵌入空间先固定，查询侧后对齐，存在用户-物品对齐不足的问题。
- **研究目标**：提出一个嵌入原生的生成式检索框架（EGR），使用单个共享LLM在同一嵌入空间中学习物品和用户表示，消除量化、分离编码器等复杂性，同时保持标准ANN服务的简洁性。

## 2. 方法论：核心思想、关键技术细节

### 核心思想
- 使用一个**共享LLM骨干网络**（Qwen3-VL-Embedding 2B）同时处理**物品路径**（编码物品元数据）和**用户历史路径**（编码用户交互序列），输出低维稠密向量（512维，L2归一化）。
- 物品直接作为嵌入写入ANN索引，用户历史编码为查询向量，通过最大内积检索。
- 采用**联合对比学习**训练：物品表示学习（IRL）和下一项预测（NIP）同时优化。

### 关键技术细节

1. **物品表示学习（IRL）**
   - 输入：物品元数据（标题、品牌、类别，可选图像）。
   - 编码：通过共享LLM + MLP投影头 → 得到物品嵌入 \( z_i \)。
   - 损失：从同一用户连续共交互的物品对 \( (p_a, p_b) \) 中提取，使用对称InfoNCE损失：
     \[
     L_{IRL} = \frac{1}{2} [ \text{InfoNCE}(z_a, z_b) + \text{InfoNCE}(z_b, z_a) ]
     \]
     其中 InfoNCE 使用 batch 内负样本。

2. **下一项预测（NIP）**
   - 输入：用户历史交互序列（事件：<view>, <add_to_cart>, <purchase> + 物品文本）。
   - 编码：通过共享LLM + MLP投影头 → 得到用户查询嵌入 \( q_u \)。
   - 目标：预测下一个交互的物品（目标物品嵌入 \( z_y \)）。
   - 损失：历史到目标的 InfoNCE 损失，并对目标嵌入应用**停止梯度（stop-gradient）**：
     \[
     L_{NIP} = \text{InfoNCE}(q_u, \text{sg}(z_y))
     \]
     停止梯度防止每个例子直接拉拽目标物品嵌入破坏索引空间稳定性。

3. **联合训练**
   - 总损失：\( L = L_{IRL} + \lambda_t L_{NIP} \)
   - 预热调度：前10%步仅激活IRL（\( \lambda_t = 0 \)），然后 \( \lambda_t \) 从0.1线性增至1.0。
   - 优化器：AdamW，学习率2e-5，余弦衰减。
   - 可训练参数：LoRA（r=128, α=256，作用于Q/K/V/O投影）约41M参数 + MLP投影头 + 温度参数。

4. **服务架构**
   - 离线索引：物品嵌入定期或近实时计算，写入ANN索引。
   - 查询检索：用户查询嵌入可预计算（每日）或在线实时生成。线上使用ANN搜索，返回Top-K物品。

## 6. 主要结论与发现

1. **公开数据集**：EGR在Amazon Reviews的Beauty、Sports、Toys上R@10均优于SASRec、TIGER、HSTU等基线，尤其在Toys上领先明显（0.0807 vs 0.0626）。
2. **数据规模**：在工业数据上R@10随训练数据从10K到10M单调提升27%，未见饱和。
3. **冷启动**：从未在训练输入中出现的目标物品（频次0）的R@10仅比高频桶（>15）低5.1%，证明对未见物品的鲁棒性。
4. **多模态**：增加产品图像输入使R@10提升6.9%（text+image vs text-only）。
5. **联合训练有效性**：完整EGR（联合+停止梯度）R@10设为100%，去掉IRL降至93.7%，去掉停止梯度降至95.3%，分离为两个模型降至86.2%，仅IRL仅26.6%。联合训练至关重要。
6. **损失调度**：保持IRL全程活动（Joint）最佳；顺序训练（先IRL后NIP）下降约26%，表明重叠阶段重要。
7. **线上部署**：增加EGR作为额外检索源，在总候选数不变下，显示量+0.15%、CTR+0.23%、CVR+2.91%。EGR提供的候选CTR/CVR分别为生产所有检索源平均的1.55×/1.53×。随后全量部署。

## 7. 优点

- **架构简洁**：无量化、无可变标识符、无令牌-物品映射，直接使用稠密向量ANN搜索，降低系统复杂度。

- **冷启动友好**：新物品只需编码元数据即可加入索引，无需重建词汇表或重新训练生成器。
