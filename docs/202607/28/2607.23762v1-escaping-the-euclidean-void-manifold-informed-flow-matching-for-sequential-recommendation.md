## 摘要
传统推荐系统通过优化观察到的用户-物品关系来捕捉用户偏好，而连续生成式推荐则额外学习合成目标物品的轨迹。流匹配通过连续嵌入空间中的中间状态，将初始噪声逐步塑造成最终的下一个物品表示，从而驱动这一过程。然而，物品目录是离散的且支持稀疏，这意味着即使是平直的欧几里得路径也可能穿过包含很少有效物品语义证据的连续区域。将这一失败形式化为欧几里得虚空，我们提出了MIRAGE——一种面向序列推荐中加速生成嵌入的流形感知修正框架，它在保持不变的直线概率路径周围修正学习到的嵌入几何。通过利用物品共现图作为底层语义流形的代理，MIRAGE将插值路径状态与局部锚点对齐，重新组织嵌入空间，使轨迹立足于有效的物品支持。MIRAGE保留了原始概率路径，并仅在训练期间使用该图，从而实现了准确高效的一步推理。在四个真实世界数据集上的大量实验表明，MIRAGE始终优于最先进的基线模型，有效提升了稀疏观测目标的性能，同时实现了稳健的整体准确率。我们的代码将在论文发表后公开。

## Abstract
Conventional recommenders capture users' preferences by optimizing observed user-item relations, whereas continuous generative recommendation additionally learns the trajectory of synthesizing a target item. Flow matching drives this process by gradually shaping initial noise into a definitive next-item representation through intermediate states in a continuous embedding space. However, item catalogs are discrete and sparsely supported, meaning even a straight Euclidean path can cross continuous regions that contain little evidence of valid item semantics. Formalizing this failure as the Euclidean void, we propose MIRAGE, a Manifold-Informed Rectification framework for Accelerated Generation of Embeddings in sequential recommendation, which rectifies the learned embedding geometry around an unchanged straight probability path. By leveraging an item co-occurrence graph as a proxy for the underlying semantic manifold, MIRAGE aligns interpolated path states with local anchors, reorganizing the embedding space to ground the trajectory in valid item support. MIRAGE retains the original probability path and uses the graph only during training, thereby enabling accurate and efficient one-step inference. Extensive experiments on four real-world datasets reveal that MIRAGE consistently outperforms state-of-the-art baselines, effectively boosting performance on sparsely observed targets while achieving robust overall accuracy. Our code will be made publicly available upon publication.

## 1. 核心问题与研究动机
- **背景**：序列推荐（SR）中，传统方法（如SASRec、LightGCN）依赖离散判别，优化目标为区分正负样本，不要求连续空间中的插值路径具备语义。而**连续生成式推荐**（如扩散模型、流匹配）通过学习从噪声到目标物品的连续轨迹，需要中间状态具有语义支持。
- **核心问题**：物品目录是离散且稀疏的，平直的欧几里得插值路径（如线性概率路径）会穿过**无有效物品语义支持的连续区域**，作者称之为**“欧几里得虚空”（Euclidean void）**。这导致中间状态缺乏局部几何证据，模型难以学习可靠的传输方向，尤其在长尾物品上表现更差。
- **现有工作不足**：FMRec、FAVE等流匹配方法专注于优化轨迹的笔直性（减少离散化误差），但未保证路径穿越语义可靠区域。增加求解步数无法解决结构性问题，因为数值积分无法合成缺失的目录支持。

## 2. 方法论：MIRAGE框架
### 核心思想
- 不改变直线概率路径，而是**修正嵌入几何**，使路径内部被有效物品语义覆盖。利用**物品共现图**作为底层语义流形的离散代理，通过拓扑正则化将插值状态与目标局部邻域锚点对齐，动态重组嵌入空间。
- 训练后推理阶段完全脱离图计算，实现**一步生成**（one-step inference），保持高效。

### 关键技术细节
- **目标恢复流骨干**：采用目标恢复参数化，直接预测干净目标嵌入。损失包括：
  - 恢复损失 \( \mathcal{L}_{\text{recov}} = \| \hat{\boldsymbol{x}}_1 - \boldsymbol{x}_1 \|^2 \)
  - 目录排序损失 \( \mathcal{L}_{\text{rank}} \)（交叉熵）
  - 历史重建损失 \( \mathcal{L}_{\text{hist}} \)
- **流形感知修正**：
  - 构建物品共现图（基于训练集上下文窗口内共现频率），为每个目标物品存储K个最高共现邻居作为锚点。
  - 时间调制权重 \( w(t) = 4t(1-t) \)，在端点（t=0或1）为零，在路径中部（t=0.5）最大，保证仅修正路径内部。
  - **硬对齐**：将插值状态拉向其最近邻锚点（梯度为 \( 2(\boldsymbol{x}_t - \boldsymbol{e}_{j^*_t}) \) ）。
  - **软对齐**（用于稀疏数据集如CDs）：通过softmax加权中心进行平滑对齐。
- 完整目标函数：\( \mathcal{L}_{\text{MIRAGE}} = \mathcal{L}_{\text{recov}} + \lambda_{\text{rank}} \mathcal{L}_{\text{rank}} + \lambda_{\text{hist}} \mathcal{L}_{\text{hist}} + \lambda_{\text{topo}} \mathcal{L}_{\text{topo}} \)
- 推理：一步欧拉采样，\( \hat{\boldsymbol{x}}_1 = f_\theta(\boldsymbol{x}_0, \epsilon, S_u) \)，然后与所有物品嵌入内积排名。

- MIRAGE在所有数据集上显著优于所有基线，尤其在稀疏长尾目标上提升更明显（如Sports长尾H@20提升14.0%，CDs长尾提升17.5%）。
